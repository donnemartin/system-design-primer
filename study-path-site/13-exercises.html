The System Design Primer — Study Path 13

Exercises: attempt these before you look at the solutions

Fourteen practice problems — eight system design prompts and six object-oriented design prompts — pulled straight out of the original repo's interview-questions tables. No hints, no diagrams, no code here. That's intentional.

How to use this page. For each system design prompt, run it through the framework from Module 01 before you check anything in Modules 14–15:

  1. Outline use cases, constraints, and assumptions
  2. Create a high-level design
  3. Design the core components
  4. Identify bottlenecks and scale the design

Give yourself a real attempt — sketch it on paper, say it out loud, or write it down — before comparing against the worked solution. The gap between your answer and the solution is where the learning happens, not the solution text itself.

System design — 8 prompts

  1. 1

    Design Pastebin.com (or Bit.ly)

    A service that stores a block of text (or a long URL) and hands back a short, shareable link.

  2. 2

    Design the Twitter timeline and search (or Facebook feed and search)

    A feed that fans out a user's posts to their followers, plus a way to search across all posts.

  3. 3

    Design a web crawler

    A system that discovers and downloads pages across the web at scale, without crawling the same page forever.

  4. 4

    Design Mint.com

    A service that aggregates a user's finances across many external bank accounts into one view.

  5. 5

    Design the data structures for a social network

    Model users, friendships/follows, and the queries a social graph needs to answer efficiently.

  6. 6

    Design a key-value store for a search engine

    A cache sitting in front of a search engine, keyed by query, built to serve read-heavy traffic fast.

  7. 7

    Design Amazon's sales ranking by category feature

    A "best sellers" list per product category that updates continuously off of purchase data.

  8. 8

    Design a system that scales to millions of users on AWS

    Start from a single server and walk forward, one bottleneck at a time, to a system that can handle millions of users.

Object-oriented design — 6 prompts

  1. 1

    Design a hash map

    Build the data structure itself: hashing, buckets, collision handling, resize.

  2. 2

    Design a least recently used (LRU) cache

    Fixed-capacity cache that evicts whatever was used least recently, in O(1) per operation.

  3. 3

    Design a call center

    Model employees of different ranks and route an incoming call to the right handler.

  4. 4

    Design a deck of cards

    Model a standard deck, hands, and a shuffle — in a way a real card game could be built on top of.

  5. 5

    Design a parking lot

    Model levels, spots of different sizes, vehicles of different sizes, and ticketing.

  6. 6

    Design a chat server

    Model users, one-to-one and group conversations, and message delivery.

When you've genuinely attempted a prompt, Module 14 (System Design Solutions) and Module 15 (Object-Oriented Design Solutions) have the worked answers — discussions, diagrams, and code.
