The System Design Primer — Study Path Module 15.1

Design a hash map

Build a key-value store from scratch — the data structure behind every dict, map, and cache you've used — supporting set, get, and remove in average O(1) time.

The problem

A hash map needs to answer "what value did I store under this key?" without scanning every entry. The trick is a hash function that turns a key into an array index, so lookups jump straight to the right slot instead of searching. The real design challenge is what happens when two different keys hash to the same slot — a collision.

Classes at a glance

  • ItemOne stored key/value pair. This is what actually lives inside a bucket.
  • HashTableOwns a fixed-size array of buckets (self.table), hashes a key down to a bucket index, and walks that bucket's list to find, insert, or remove an Item.

Key design decisions

  • Separate chaining for collisions. Each bucket is a plain list. When two keys land on the same index, the new Item is just appended to that bucket's list instead of needing open addressing or probing to find another slot.
  • The hash function is intentionally simple: key % size. That only works cleanly for integer keys and assumes the table size never changes — good enough to demonstrate the mechanism in an interview, but a real implementation would hash arbitrary key types (strings, tuples) and handle resizing.
  • get and remove raise KeyError on a missing key, mirroring the contract Python's built-in dict already follows.
What this solution deliberately leaves out — and what an interviewer will likely push on next: resizing and rehashing. As more items are added, the average bucket length grows past O(1) unless the table grows and every existing item gets rehashed into a bigger array. That's the natural next question to raise yourself.

class Item(object):

    def __init__(self, key, value):
        self.key = key
        self.value = value


class HashTable(object):

    def __init__(self, size):
        self.size = size
        self.table = [[] for _ in range(self.size)]

    def _hash_function(self, key):
        return key % self.size

    def set(self, key, value):
        hash_index = self._hash_function(key)
        for item in self.table[hash_index]:
            if item.key == key:
                item.value = value
                return
        self.table[hash_index].append(Item(key, value))

    def get(self, key):
        hash_index = self._hash_function(key)
        for item in self.table[hash_index]:
            if item.key == key:
                return item.value
        raise KeyError('Key not found')

    def remove(self, key):
        hash_index = self._hash_function(key)
        for index, item in enumerate(self.table[hash_index]):
            if item.key == key:
                del self.table[hash_index][index]
                return
        raise KeyError('Key not found')
