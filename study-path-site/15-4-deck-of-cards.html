The System Design Primer — Study Path Module 15.4

Design a deck of cards

Model a generic deck of playing cards so it can be reused across different card games — here specialized for Blackjack — without rewriting the deck or card mechanics for each game.

The problem

"A deck of cards" sounds simple until you notice that what a card's value means depends entirely on the game: an Ace is 1 or 11 in Blackjack, high or low in Poker, and worth nothing in War except for comparison. A good design keeps the deck and dealing mechanics generic, and pushes game-specific scoring into a subclass.

Classes at a glance

  • SuitEnum: HEART, DIAMOND, CLUBS, SPADE.
  • CardAbstract base. Tracks suit and availability, but leaves what "value" means to subclasses.
  • BlackJackCardA Card whose value follows Blackjack rules: aces score 1, face cards (Jack/Queen/King) score 10.
  • HandA generic collection of cards with a score() that sums card values.
  • BlackJackHandOverrides scoring to handle the ace-is-1-or-11 ambiguity, picking the best legal total at or under 21.
  • DeckAn ordered stack of cards with a deal pointer and a shuffle operation.

Key design decisions

  • Card.value is an abstract property, not a plain field. That's the whole trick for reuse: it forces every concrete card type (Blackjack, Poker, War, ...) to define its own meaning of "value" while sharing the same suit/availability plumbing.
  • Dealing advances a pointer instead of removing cards from a list. Deck.deal_card() reads self.cards[self.deal_index], marks that card unavailable, and increments the index — cheaper than mutating the underlying list, and remaining_cards() is then just subtraction.
  • Blackjack's hardest rule — ace flexibility — is isolated in one method. BlackJackHand.score() is written generically against whatever possible_scores() returns (every legal total given each ace counted as 1 or 11), then picks the highest total that doesn't bust, or the lowest bust if there's no way to avoid it.
Two stubs to know about before you run this: BlackJackHand.possible_scores() is left as pass — it's the actual hard part of Blackjack scoring (enumerating every ace-high/ace-low combination) and is the natural place to keep building. And Deck.shuffle() is also a no-op stub, so as shipped this deck never actually shuffles; a real implementation would use something like random.shuffle(self.cards).

from abc import ABCMeta, abstractmethod
from enum import Enum
import sys


class Suit(Enum):

    HEART = 0
    DIAMOND = 1
    CLUBS = 2
    SPADE = 3


class Card(metaclass=ABCMeta):

    def __init__(self, value, suit):
        self.value = value
        self.suit = suit
        self.is_available = True

    @property
    @abstractmethod
    def value(self):
        pass

    @value.setter
    @abstractmethod
    def value(self, other):
        pass


class BlackJackCard(Card):

    def __init__(self, value, suit):
        super(BlackJackCard, self).__init__(value, suit)

    def is_ace(self):
        return True if self._value == 1 else False

    def is_face_card(self):
        """Jack = 11, Queen = 12, King = 13"""
        return True if 10 < self._value <= 13 else False

    @property
    def value(self):
        if self.is_ace() == 1:
            return 1
        elif self.is_face_card():
            return 10
        else:
            return self._value

    @value.setter
    def value(self, new_value):
        if 1 <= new_value <= 13:
            self._value = new_value
        else:
            raise ValueError('Invalid card value: {}'.format(new_value))


class Hand(object):

    def __init__(self, cards):
        self.cards = cards

    def add_card(self, card):
        self.cards.append(card)

    def score(self):
        total_value = 0
        for card in self.cards:
            total_value += card.value
        return total_value


class BlackJackHand(Hand):

    BLACKJACK = 21

    def __init__(self, cards):
        super(BlackJackHand, self).__init__(cards)

    def score(self):
        min_over = sys.MAXSIZE
        max_under = -sys.MAXSIZE
        for score in self.possible_scores():
            if self.BLACKJACK < score < min_over:
                min_over = score
            elif max_under < score <= self.BLACKJACK:
                max_under = score
        return max_under if max_under != -sys.MAXSIZE else min_over

class Deck(object):

    def __init__(self, cards):
        self.cards = cards
        self.deal_index = 0

    def remaining_cards(self):
        return len(self.cards) - self.deal_index

    def deal_card(self):
        try:
            card = self.cards[self.deal_index]
            card.is_available = False
            self.deal_index += 1
        except IndexError:
            return None
