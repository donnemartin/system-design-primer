The System Design Primer — Study Path Module 15

Object-Oriented Design Solutions

Six classic OOD interview prompts, each modeled with a small class hierarchy instead of a full system diagram. These are deliberately sketch-level — stubbed methods and all — because that's the level of detail an interview actually rewards: the shape of the classes and how they relate, not a finished, bug-free program.

Try each problem yourself first using Module 13's Exercises page before opening its solution here — the value is in the attempt, not the answer.
  1. 15.1
    Hash map

    A key-value store with separate chaining for collisions.

  2. 15.2
    LRU cache

    Hash map plus doubly linked list for O(1) recency tracking and eviction.

  3. 15.3
    Call center

    Ranked employees with an escalation chain and a fallback queue.

  4. 15.4
    Deck of cards

    A reusable card/deck model specialized for Blackjack scoring.

  5. 15.5
    Parking lot

    Multi-level parking with per-vehicle fit rules and multi-spot vehicles.

  6. 15.6
    Online chat

    Users, friend requests, and private vs. group conversations.
