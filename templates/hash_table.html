#️⃣ Hash Table

A hash table that stores key-value pairs using chaining for collision resolution. Average O(1) operations for set, get, and remove.

Implementation Details

  • Hash Function: key % table_size
  • Collision Resolution: Chaining (linked lists)
  • Table Size: 10 buckets
  • Time Complexity: O(1) average, O(n) worst case
